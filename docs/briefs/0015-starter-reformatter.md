# Brief 0015 — starter reformatter: restructure a prose starter into manuscript form, output for copy-paste
Status: done
Complexity: high
PLAN sections: §19 (cold start: the first request lacks demonstrations, so a *manually prepared or hand-corrected* seed is recommended — substantial prose, tag/buffer alternation, the external character appearing naturally, no artificial handoff; this brief gives the collaborator a machine-assisted way to produce such an exemplar from an ordinary-prose starter, still hand-checked and hand-placed), §23 (host requirements are behaviours, and "request model continuation" is the only one this feature uses; it adds no host requirement and no configuration), §20 (text that becomes a persistent demonstration should be checked first, and the check is advisory to the human, never a gate — hence an output the collaborator reads and moves by hand)
Invariants touched: INV-2 (the rewrite output must not contain a block committing the externally owned figure; the sanitiser drops such a block instead of letting it become a greeting that demonstrates the wrong thing), INV-3 / INV-10 (the rewrite is a side channel: `generate_interceptor` never runs for `generateRaw`, and nothing the call sends or returns enters `chat[]`, canonical state, capture, frontier, freeze or recovery), `docs/protocol/invariants.md#enforcement-model` (the rewrite instruction is prompt-level scene direction, not a code-enforced schema — `docs/decisions/0001-prompt-level-grammar.md`)

## Goal
The extension drawer gains one more element group: a textarea for a starter written in ordinary prose, a **Restructure** button that asks the currently configured model — through one `generateRaw` call carrying `MANUSCRIPT_SYSTEM_PROMPT` as its system prompt and an OOC-tagged restructuring instruction as its prompt — to re-set that passage in the manuscript's tagged-block form, a read-only output textarea holding the sanitised result, a **Copy** button, and a one-line hint telling the collaborator where to paste it. The extension writes nothing anywhere: no character card, no chat, no canonical state, no setting. Moving the text into the character's Alternate Greetings list is the collaborator's own act in SillyTavern's character editor (user ruling, 2026-09-12: "it should just have an output box that the user can then copy and paste over to the alternate greeting list").

## In scope
- **Create `src/starter.js`** — three exports, no module-level side effect, no DOM, and (per `tests/bootstrap.test.js`'s scan) no occurrence of the string `SillyTavern`; the host is reached only through `getCtx()` imported from `./host.js`.
  - `REWRITE_INSTRUCTION` — the exact frozen string below, exported so tests assert on it without re-deriving it:

    ```
    [OOC: Restructure the passage below into the manuscript's form — a tagged block for each figure's speech, action and intent, narration between them. Keep every event, every line of dialogue and every detail; change only the shape on the page. Add nothing that is not already there. Return the restructured passage alone.]
    ```

    It is scene direction in the OOC register, not rules-lawyering: it names no mechanism, no host, no character and no macro, and it passes the same forbidden-vocabulary lists `tests/prompt.test.js:50-83` applies to the system prompt. The OOC frame exists because the same preset and system prompt are in force and this one call is deliberately off-story (`docs/decisions/0001-prompt-level-grammar.md`). Do not reword it during implementation; a change to this string is a new brief.
  - `buildRewriteRequest(starterText, literal)` → `{ systemPrompt, prompt }`, pure. `systemPrompt` is `MANUSCRIPT_SYSTEM_PROMPT` by identity (`Object.is`), never a copy or a concatenation. `prompt` is `` `${REWRITE_INSTRUCTION}\n\n${body}` `` where `body` is `starterText` trimmed and passed through the same reserved-literal block removal `sanitiseRewrite` uses (one shared module-local helper, one code path): the model is never shown a block that commits the externally owned figure, so it is never invited to produce one. `literal` is the value of `reservedLiteral(ctx)`; an empty-string or nullish `literal` means "no persona, nothing reserved" and the removal step is skipped, never guessed at. Throws nothing; an empty/whitespace `starterText` yields the instruction alone with no trailing blank line, and the caller is what refuses to send it.
  - `sanitiseRewrite(text, literal)` → string, pure. In order: strip a leading and/or trailing line that is an `[OOC: …]` echo; strip an enclosing code fence (``` or ```` with an optional language word) and any stray fence lines; parse with `parseManuscript` and drop every block whose tag header is the reserved literal, deciding from `block.actor` / `findTagLiteral(block.raw, actor)` — a block *beginning* with the literal only, never a mid-block occurrence; rejoin survivors with one blank line; trim. Never returns `undefined`; an all-reserved input returns `''`.
  - `restructureStarter(text, ctx = getCtx())` → `Promise<string>`, `async`. Computes `literal = reservedLiteral(ctx)`, builds the request, calls `await ctx.generateRaw({ prompt, systemPrompt })` — **one options object, exactly these two keys**: no `api`, no `responseLength`, no `prefill`, no `jsonSchema`, no `instructOverride`, no `quietToLoud` (`docs/api/sillytavern.md#generateraw`) — and returns `sanitiseRewrite(String(result ?? ''), literal)`. Returns `''` and logs once through `console.error` with `LOG_PREFIX` if `generateRaw` is absent or rejects; it never throws and never notifies (the UI owns all user-facing messaging). No other generation path, no `fetch`, no `getRequestHeaders`, no slash command; `generateQuietPrompt` is explicitly the wrong tool (`#generatequietprompt`: full pipeline, history, card, WI and the interceptor all run).

Its value is never read from or written to any store: no `extensionSettings`, no `chatMetadata`, no `localStorage`, no `saveSettingsDebounced`. It is not repopulated on re-render, and `renderSettings` stays idempotent.
  - `div.uid-settings-actions` holding `button.menu_button.uid-starter-restructure` (id `uid_starter_restructure`, `type="button"`, label "Restructure") and `button.menu_button.uid-starter-copy` (id `uid_starter_copy`, `type="button"`, label "Copy").
  - `textarea.uid-starter-output` (id `uid_starter_output`, `rows="8"`, `readOnly = true`) holding the sanitised result, so it is selectable and scrollable. Read-only means the `readOnly` property, set in JS; the value is assigned with `.value` and never parsed as HTML. Hidden (`hidden` property) until a rewrite returns non-empty text.
  - `div.uid-settings-note.uid-starter-hint` with exactly the one line `Paste into the character's Alternate Greetings.`

The `input` event on the input textarea and the completion of a rewrite are the only triggers. No CHAT_CHANGED wiring, no new event subscription, no `index.js` line.

## Isolation note (why no guards are needed)
`generateRaw` replaces prompt and system prompt wholesale — no character card, no world info, no persona, no chat history — and `runGenerationInterceptors` is **never** called for it, so `frontier`'s `generate_interceptor` cannot touch this request (`docs/api/sillytavern.md#generateraw`). It also does not fire `GENERATION_STARTED` or `CHAT_COMPLETION_SETTINGS_READY`, so `boundary` neither arms nor applies its stop strings on the chat-completion path here; it does fire `CHAT_COMPLETION_PROMPT_READY` / `GENERATE_AFTER_COMBINE_PROMPTS`, which this extension currently subscribes to in no module (`index.js` wires only GENERATION_STARTED, the two settings-ready events, STREAM_TOKEN_RECEIVED, MESSAGE_RECEIVED and MESSAGE_SENT). Should `boundary`'s stop strings or its stream-side stop reach this call on some path, that is **acceptable and desirable** — a rewrite that halts before the externally owned figure's tag is exactly the output wanted — and `sanitiseRewrite` is the guarantee either way. `generateRaw` adds nothing to `chat[]`, so `capture` and `recovery` never see it.
