# Decision records

Template:

```
# NNNN — <title>
Date: YYYY-MM-DD
Brief: docs/briefs/NNNN-<slug>.md
PLAN: §n

## Decision
One paragraph.

## Alternatives rejected
- <alternative> — <why not>

## Consequences
- <what this commits us to>
```
