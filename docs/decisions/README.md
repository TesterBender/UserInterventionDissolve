# Decision records

`NNNN-<slug>.md`, numbered in creation order. Required whenever a change adds a dependency, deviates from a PLAN.txt recommendation, or works around a backend-specific SillyTavern behaviour.

Template:

```
# NNNN — <title>
Date: YYYY-MM-DD
Brief: docs/briefs/NNNN-<slug>.md
PLAN: §n

## Decision
One paragraph.

## Alternatives rejected
- <alternative> — <why not>

## Consequences
- <what this commits us to>
```
